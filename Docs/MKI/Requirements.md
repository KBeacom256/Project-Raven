MISSION STATEMENT: Design and build a durable, portable multirotor UAV that serves as the primary development and test platform for Project Raven. The aircraft shall support experimentation with flight software, autonomous navigation, sensors, and hardware modifications while remaining economical to repair and operate.

Primary objectives:
- Learn basic UAV engineering
- Test ardupiolet features
- Test firmware updates
- Test new sensors
- Test autonomous flight
- Test waypoint missions
- Test GPS navigation
- Practice manual flight
- Validate hardware before scaling to Mk II

Design priorities:
- Reliability
- Durability
- Wind handling
- Flight time
- Modularity

Performance targets:
- Flight time          == 20-30 min
- Cruise speed         == 20-35 mph
- Top speed            == 45-60 mph not build requirement
- Wind resistance      == stable in
- Flight controller    == ArduPilot compatible
- GPS                  == Yes
- Autonomous flight    == Yes
- HD recording camera  == Yes
- Easy repair          == Yes
- Backpack portable    == Yes
- Telementry           == Yes
