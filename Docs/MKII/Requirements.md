MISSION STATEMENT: Design and build a larger UAV capable of advanced autonomous missions, significant payload capacity, and reliable operation in challenging environmental conditions while serving as the flagship engineering platform of Project Raven.
Primary Goals:
- Long-range autonomous missions
- Payload testing
- Thermal imaging
- Mapping
- AI experiments (future)
- Computer vision
- Navigation research
- Wind testing
- Long-endurance flight

Payload goals:
Raven MKII should be capable of carrying possible combinations of >
- Thermal camera
- FPV navigation camera
- HD recording camera
- Telementary radio
- GPS
- Companion computer
- Future sensors

Performance targets:
- Flight time                   == 35-50 min
- Payload capacity              == 2-5 Ib (0.9-2.3 kg)
- Wind Resistance               == Stable in 25-35 mph winds
- Autonomous flight             == Yes
- Waypoint missions             == Yes
- Precision landing             == Yes future
- Thermal camera support        == Yes
- HD camera support             == Yes
- Telementry                    == Yes
- Companion computer            == Future
- Expandable payload mounting   == Yes
